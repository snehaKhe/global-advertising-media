# Country page geography

`countries-source.json` and `states-source.json` were downloaded on October 23, 2026 from the Countries States Cities Database:

- https://github.com/dr5hn/countries-states-cities-database
- https://raw.githubusercontent.com/dr5hn/countries-states-cities-database/master/json/countries.json
- https://raw.githubusercontent.com/dr5hn/countries-states-cities-database/master/json/states.json

The source and derived `country-pages.json` geography are distributed under the Open Database License v1.0. See `GEOGRAPHY-LICENSE.txt`. Attribution appears on every country page. The derived JSON is downloadable from each page.

The selected countries match the 195 flags in Seo.html. Regional entries use top-level divisions where the dataset identifies parent relationships. Geographic names do not establish Google Ads targeting availability, a local office, or previous client experience.

Google Ads availability guidance checked October 23, 2026:

- https://support.google.com/google-ads/answer/6163740?hl=en
- https://support.google.com/authorizedbuyers/answer/1325008?hl=en
- https://support.google.com/google-ads/answer/10835274?hl=en

Cuba, Iran, and North Korea use restricted-market wording. Russia uses paused-market wording. All other pages require account, billing, campaign, and targeting eligibility checks before launch. These policy statements should be reviewed periodically.

Client scenarios are explicitly illustrative. No client names, ratings, quotations, revenue figures, or performance statistics have been invented. Replace the scenario and review content in the generator with client-approved material when available.

`state-pages.json` is a derived ODbL dataset for the 3,793 named areas already listed on country pages. Each record includes its country, display name, administrative division type, native name/timezone when supplied, source record ID, and page slug. No city lists or business statistics have been invented. Native names and time zones are shown only when present in the source.
